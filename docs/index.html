Тач-управление

Мультитач: джойстик руля, педали, ручник. Всё под большой палец.

Ноль ассетов

Графика и звук генерируются кодом. APK весит считанные мегабайты.

Установка

  1. Нажми СКАЧАТЬ APK выше с телефона.
  2. Открой файл CrashForge.apk.
  3. Разреши установку из неизвестных источников.
  4. Установи и открой. Нужен Android 7+ и arm64.

Управление

  1. Слева - джойстик руля.
  2. Справа - GAS и BRK. Держи BRK на месте - задняя передача.
  3. P-BRK - ручник для дрифта.
  4. MODE - режим, CAR - ещё машина, RESET - починить.
  5. SLOW - слоумо, CAM - камера. Свайп по свободной зоне - обзор.
