Кузов мнётся по-настоящему

49 узлов и ~1000 балок. Пластическая деформация, разрыв связей, отваливающиеся колёса и панели.

Честные шины

Модель Pacejka: продольное скольжение, угол увода, эллипс трения. Юз, дрифт, следы на асфальте.

5 режимов

Песочница, краш-тест в стену, трамплин, дерби с ИИ и гидравлический пресс.

Замедление времени

Кинематографичная камера автоматически включается на сильном ударе.

Тач-управление

Мультитач: джойстик руля, педали газа/тормоза, ручник. Всё под большой палец.

Ноль ассетов

Вся графика и звук генерируются кодом. APK весит считанные мегабайты.

Как установить

  1. Нажми СКАЧАТЬ APK выше с телефона.
  2. Открой скачанный файл CrashForge.apk.
  3. Android спросит разрешение — «Установка из неизвестных источников» → Разреши для браузера/файлового менеджера.
  4. Установи → Открой. Игра сразу в ландшафте.
  5. Требуется Android 7.0+ и процессор arm64 (почти любой телефон после 2017).

Управление

  1. Слева — круглый джойстик руля.
  2. Справа — GAS и BRK. Держи BRK на месте → задняя передача.
  3. P-BRK — ручник, блокирует задние колёса (дрифт).
  4. MODE — сменить режим, CAR — заспавнить ещё машину, RESET — починить.
  5. SLOW — слоумо, CAM — вид камеры. Свайп по свободной области — обзор.
